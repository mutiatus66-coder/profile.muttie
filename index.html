Tentang

MS

Halo, saya Muti'atus Sholehah, junior web developer yang senang membangun hal-hal dari nol — mulai dari belajar aplikasi web dengan Laravel sampai mencoba mempelkajari game kecil yang jalan langsung di browser pakai HTML Canvas.

Saya suka proyek yang punya sisi statis (landing page, profil, dokumentasi) maupun dinamis (aplikasi dengan data, autentikasi, interaksi real-time). Buat saya, kode yang bagus itu yang jelas dibaca dan enak dipakai orang lain.

Saat ini saya siswa SMKN Takeran, jurusan Rekayasa Perangkat Lunak (RPL), dan sedang melaksanakan magang di Dinas Komunikasi dan Informatika Magetan. Saya memiliki pengalaman mengikuti bootcamp di PT Ubig Malang serta pernah berkompetisi di Lomba Kompetensi Siswa (LKS) tingkat provinsi bidang Web Technology.

Di luar dunia pemrograman, saya suka menulis dan membaca — baik cerita fiksi maupun non-fiksi. Saya juga memiliki bakat menggambar dan termasuk orang yang cepat memahami pelajaran baru. Saya selalu antusias untuk mengeksplor hal-hal baru dan kehidupan baru.

Saya bercita-cita ingin menjadi seorang guru, atau setidaknya menjadi wisudawan pertama di keluarga saya. Saya juga memiliki ketertarikan besar di bidang IoT — di SMKN Takeran, saya mendapatkan ilmu IoT yang cukup membuat saya terkesan.

Pengalaman Magang di Diskominfo Magetan: Selama magang, saya belajar banyak tentang Laravel 13, Playwright, Selenium, SQLite, cara menggunakan table, push/pull di GitHub, serta CodeIgniter. Salah satu project yang saya kerjakan adalah Rumah Inovasi Magetan yang sudah mencapai 80-90% jadi.
